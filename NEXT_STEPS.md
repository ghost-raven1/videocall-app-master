## ✅ Проверка ключевых пользовательских сценариев

**Цель:** Убедиться, что после рефакторинга и до/после деплоя корректно работают аудио/видео, демонстрация экрана, статусы звонка и подключение по прямой ссылке.

### 1. Звук между пользователями
- [ ] При 2 участниках: оба слышат друг друга (P2P/SFU по текущей конфигурации)
- [ ] При 3+ участниках: звук слышен у всех, нет одностороннего звука
- [ ] Мьют/анмьют микрофона у одного участника корректно отражается у остальных
- [ ] Переключение устройств ввода (микрофон) не ломает звук в активном звонке

### 2. Видео и отображение участников
- [ ] Участники видят друг друга в сетке участников
- [ ] Счётчик участников и список участников соответствуют реальному количеству подключённых пиров
- [ ] Отключение/включение камеры корректно обновляет превью и карточку участника у всех
- [ ] При подключении нового участника уже существующие участники продолжают видеть друг друга (нет пропажи потока)

### 3. Демонстрация экрана
- [ ] Локальная демонстрация экрана видна самому пользователю (оверлей/отдельный блок)
- [ ] Демонстрация экрана пользователя видна всем остальным участникам
- [ ] Демонстрация экрана других участников отображается у локального пользователя
- [ ] Остановка демонстрации корректно убирает соответствующие элементы UI у всех
- [ ] В SFU‑режиме screen‑share трек действительно уходит через SFU и виден всем участникам

### 4. Статусы звонка и UI состояния
- [ ] Статус звонка корректно переключается: `connecting → connected → disconnected`
- [ ] Оверлей "Connecting..." исчезает после успешного установления соединения
- [ ] При разрыве соединения/ошибке отображается понятное сообщение и/или состояние `reconnecting`/`failed`
- [ ] Статусы участников (подключается / подключен / отключён) синхронизированы с реальным состоянием WebRTC/WebSocket

### 5. Подключение по прямой ссылке (deep link)
- [ ] Переход по прямому URL комнаты (вставка ссылки в адресную строку браузера) приводит к открытию страницы звонка
- [ ] Если требуется имя пользователя и/или пароль комнаты — показывается форма, после ввода происходит корректное подключение
- [ ] При открытии ссылки в новом браузере/инкогнито пользователь автоматически подключается к указанной комнате (при валидных параметрах)
- [ ] Неверный или просроченный код комнаты обрабатывается корректно (понятная ошибка, нет бесконечного "Connecting...")
