# 🧪 Руководство по локальному тестированию видеозвонков

## Быстрый старт

### 1. Запуск всех сервисов

```bash
# Из корня проекта
cd /Users/aleksejstarodubcev/Downloads/videocall-app-master

# Запуск dev окружения
./scripts/start-dev.sh

# Или вручную:
# Terminal 1 - Backend
cd backend
python manage.py runserver 0.0.0.0:8000

# Terminal 2 - Frontend
cd videocall-frontend
npm run dev

# Terminal 3 - SFU Node (опционально, для 3+ участников)
cd streaming-node
go run main.go
```

### 2. Проверка доступности сервисов

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000/api/
- **SFU Node**: http://localhost:8080 (если запущен)

### 3. Тестирование звонка с 2 участниками

#### Вариант A: Два браузера на одной машине

1. **Браузер 1 (Chrome)**:
   - Откройте http://localhost:3000
   - Создайте комнату
   - Скопируйте код комнаты (например: V2UJCG)

2. **Браузер 2 (Firefox или Chrome в режиме инкогнито)**:
   - Откройте http://localhost:3000
   - Введите код комнаты
   - Присоединитесь

#### Вариант B: Два устройства в одной сети

1. Узнайте IP адрес вашей машины:
   ```bash
   # macOS/Linux
   ifconfig | grep "inet "
   
   # Windows
   ipconfig
   ```

2. На втором устройстве откройте: `http://<YOUR_IP>:3000`

3. Используйте тот же код комнаты

### 4. Тестирование с 3+ участниками (SFU режим)

1. Убедитесь что SFU Node запущен:
   ```bash
   cd streaming-node
   go run main.go
   ```

2. Создайте комнату (SFU автоматически включится при 3+ участниках)

3. Присоедините 3+ участников

### 6. Отладка проблем

#### Проблема: "Initializing..." не меняется

**Решение**:
1. Откройте DevTools (F12)
2. Проверьте консоль на ошибки
3. Проверьте вкладку Network - есть ли WebSocket соединение
4. Проверьте что backend запущен на порту 8000

#### Проблема: Звук не работает

**Решение**:
1. Проверьте разрешения браузера для микрофона
2. Проверьте что микрофон не используется другим приложением
3. В DevTools → Console проверьте логи добавления аудио треков

#### Проблема: Не могу выйти из комнаты

**Решение**:
1. Проверьте что кнопка "End Call" кликабельна
2. Проверьте консоль на ошибки при клике
3. Попробуйте закрыть вкладку и открыть заново

#### Проблема: Видео не отображается

**Решение**:
1. Проверьте разрешения камеры
2. Проверьте что камера не используется другим приложением
3. Проверьте логи в консоли - должны быть сообщения о добавлении треков

### 7. Полезные команды для отладки

```bash
# Проверка что backend работает
curl http://localhost:8000/api/health/

# Проверка что frontend работает
curl http://localhost:3000

# Проверка WebSocket (нужен wscat)
npm install -g wscat
wscat -c ws://localhost:8000/ws/room/<ROOM_ID>/

# Просмотр логов backend
cd backend
python manage.py runserver 0.0.0.0:8000 --verbosity 2
```

### 8. Тестирование на разных устройствах

#### Локальная сеть:
1. Узнайте IP адрес машины с запущенным сервером
2. На других устройствах откройте `http://<IP>:3000`
3. Убедитесь что все устройства в одной сети

#### Через ngrok (для тестирования из интернета):
```bash
# Установите ngrok
brew install ngrok  # macOS
# или скачайте с https://ngrok.com/

# Запустите туннель
ngrok http 3000

# Используйте предоставленный URL для доступа
```

### 9. Проверка статуса соединения

В консоли браузера проверьте:
```javascript
// Проверка WebSocket
window.webrtcStore?.websocket?.readyState
// Должно быть 1 (OPEN)

// Проверка connection state
window.webrtcStore?.connectionState
// Должно быть 'connected' после подключения

// Проверка участников
window.webrtcStore?.remoteParticipants
// Должен содержать массив участников
```

### 10. Типичные проблемы и решения

| Проблема | Решение |
|----------|---------|
| CORS ошибки | Проверьте настройки CORS в `backend/videocall_app/settings.py` |
| WebSocket не подключается | Проверьте что backend запущен и порт 8000 доступен |
| Видео черное | Проверьте разрешения камеры в браузере |
| Звук не работает | Проверьте разрешения микрофона и что он не muted |
| "Initializing..." не меняется | Проверьте логи в консоли, возможно проблема с WebSocket |
| Не могу выйти | Проверьте что `handleEndCall` вызывается, проверьте консоль |

### 11. Тестирование с разными браузерами

Рекомендуется тестировать на:
- ✅ Chrome/Chromium (лучшая поддержка WebRTC)
- ✅ Firefox
- ✅ Safari (macOS/iOS)
- ⚠️ Edge (должен работать, но может быть проблемы)

### 12. Проверка производительности

В DevTools:
1. Откройте Performance tab
2. Запишите сессию звонка
3. Проверьте FPS, использование CPU/Memory
4. Проверьте Network tab - битрейт видео/аудио

---

**Примечание**: Для полного тестирования SFU режима рекомендуется использовать минимум 3 браузера/устройства.
